IPv4 Subnetting, Netmasks & CIDR Tutorial

Complete Conceptual Guide for Network and Storage Administrators

1. What is an IP Address?

An IPv4 address is a 32-bit number used to uniquely identify a device on a network.

Example:

192.168.10.25

IPv4 contains 4 octets:

Octet1 Octet2 Octet3 Octet4
192 168 10 25

Each octet ranges from 0 to 255.

2. Binary Number System

Computers understand only binary digits (0 and 1).

Bit Position 128 64 32 16 8 4 2 1
Binary Weight 2⁷ 2⁶ 2⁵ 2⁴ 2³ 2² 2¹ 2⁰

3. Binary to Decimal Conversion

Example 1

10000000

= 128

Because only the 128 bit is ON.

Example 2

11110000

128 + 64 + 32 + 16

= 240

Example 3

11111111

128+64+32+16+8+4+2+1

= 255

4. Decimal to Binary Conversion

Convert 192

128 64 32 16 8 4 2 1
1 1 0 0 0 0 0 0

192 = 11000000

5. What is a Netmask?

Netmask separates:

  • Network Portion
  • Host Portion

Example:

255.255.255.0

Binary:

11111111.11111111.11111111.00000000

1 = Network Bit
0 = Host Bit

6. CIDR Notation

CIDR = Classless Inter-Domain Routing

Instead of writing:

255.255.255.0

we write:

/24

Because there are 24 network bits.

CIDR Netmask Hosts
/24 255.255.255.0 254
/25 255.255.255.128 126
/26 255.255.255.192 62
/27 255.255.255.224 30
/28 255.255.255.240 14
/29 255.255.255.248 6
/30 255.255.255.252 2

8. Example: IP 10.10.0.100/24

IP Address:

10.10.0.100

Mask:

255.255.255.0

Network Address:

10.10.0.0

Broadcast Address:

10.10.0.255

Host Range:

10.10.0.1 - 10.10.0.254

9. Example: IP 10.10.0.100/25

Mask:

255.255.255.128

Block Size:

128

Subnets:

  • 10.10.0.0 - 10.10.0.127
  • 10.10.0.128 - 10.10.0.255

IP 10.10.0.100 belongs to first subnet.

Network = 10.10.0.0

Broadcast = 10.10.0.127

Usable Hosts = 10.10.0.1 - 10.10.0.126

10. Fast Subnet Calculation Trick

Block Size =

256 - Last Mask Octet

Example

255.255.255.240

256 - 240 = 16

Subnets increment by 16:

0,16,32,48,64,80,96,112...
