Physical storage, from the ground up

A bit is just a voltage level someone agreed to measure.

Every write your storage system performs ends here — at a tiny trapped charge inside a NAND cell. This is what that charge is, how many values it can represent, and how a system like ONTAP finds its way back to it.

The controller doesn't see a "bit." It sees a charge, and decides which band it falls into.

01 — The cell

Think of it as a glass that holds a charge, not a value.

A NAND cell is a microscopic trap for electrons. To read it, the controller measures how much charge is sitting inside — a voltage. It never reads "1" or "0" directly. It reads a water level, then decides what that level means.

The physical range — empty to full — never changes. What changes between SLC, TLC, and QLC is how finely that same range gets sliced.

Slice it into 2 bands and you get near-zero ambiguity. Slice it into 16 and every band is a sliver — read the charge a fraction off, and the controller reads the wrong number entirely.

02 — One cell, one number

More bits per cell means more bands to tell apart — not more bits actually stored.

A QLC cell doesn't hold "16 bits." It holds one 4-bit number, chosen from 16 possible values — the same way a 4-digit combination lock holds one combination, picked from 10,000 possibilities. Pick a type below and watch the margin shrink as bits per cell go up.

03 — Zooming out

Cells don't work alone — they're organized in a strict physical hierarchy.

You can't read or erase a single cell. The drive operates on groups of cells, and each grouping level has its own rules — this is a real physical nesting, not an arbitrary order.

~nmCell

One trapped charge. Holds one value: 1 bit (SLC) up to 5 bits (PLC).

~16KBPage

Thousands of cells. This is the smallest unit you can read or write — you can never touch a single cell in isolation.

~MBBlock

Hundreds of pages. Erasing only happens at this level — write a page, but you must erase the whole block, even to reclaim one stale page.

~10s of GBDie

Thousands of blocks on one piece of silicon.

~100s of GBPackage

Multiple dies stacked vertically — modern 3D NAND stacks 100+ layers to raise density without a larger footprint.

TBsDrive

Many packages, coordinated by an onboard controller that handles wear-leveling, garbage collection, and error correction across the entire array.

04 — Two black boxes, stacked

ONTAP never sees a cell. It stops at the logical block address.

A storage OS and the SSD's own firmware split the work cleanly. Neither one knows the other's internals — and that separation is deliberate.

ONTAP / WAFL

Tracks volumes, aggregates, and RAID groups. Writes a file to a logical block address — "LBA 48213 on SSD 7" — and stops there.

↓ hands off a plain LBA, nothing more ↓
SSD controller (FTL)

Owns the actual physical placement: which die, block, page, and cells. Maintains its own private map from LBA → physical location.

↓ moves data freely underneath, for its own reasons ↓
Wear-leveling · Garbage collection · Bad-block remap

The same LBA can point to different physical cells over time. ONTAP never notices — it just asks for LBA 48213 and gets the right data back.

This is why NetApp can write one filesystem that works across SSDs from any vendor, any NAND type — the block-device interface (NVMe/SAS) hides all the physical detail underneath.

Reference

Quick glossary

Voltage state

The amount of trapped charge in a cell, measured on read. Each distinguishable level maps to one binary value.

FTL

Flash Translation Layer — the SSD's own firmware that maps logical addresses to physical cell locations.

Wear-leveling

Spreading writes evenly across all blocks so no single area wears out from repeated erase cycles.

Write amplification

Extra physical writes caused by having to erase a whole block to reclaim a single stale page.

P/E cycle

One program (write) plus one erase — the basic unit of wear a NAND cell can survive before failing.

LBA

Logical Block Address — the flat, virtual address the OS writes to. Never tied to a fixed physical location.
