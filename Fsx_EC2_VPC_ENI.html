AWS EC2, ENI & VPC

Storage Administrator's Guide to AWS Networking Fundamentals

Introduction

As storage administrators moving from traditional data centers to cloud environments, understanding AWS networking concepts is essential. The three most common building blocks you will encounter are:

  • EC2 (Elastic Compute Cloud)
  • ENI (Elastic Network Interface)
  • VPC (Virtual Private Cloud)

These components form the foundation of services such as:

  • Amazon FSx for ONTAP
  • Cloud Volumes ONTAP (CVO)
  • AWS Native Applications
  • Hybrid Cloud Storage Solutions

1. What is EC2?

EC2 (Elastic Compute Cloud) is AWS's virtual machine service. It provides compute resources similar to physical servers or VMware virtual machines.

2. What is an ENI?

ENI stands for Elastic Network Interface. Think of it as a virtual network card (NIC).

Just as physical servers can have multiple NICs, AWS instances can have multiple ENIs.

ENI Contains

  • Private IP Address
  • Secondary IP Addresses
  • MAC Address
  • Security Groups
  • Network Connectivity

FSx for ONTAP Example

When you deploy FSx for ONTAP:

  1. A VPC provides networking.
  2. Subnets provide placement.
  3. ENIs are created automatically.
  4. Clients connect through ENIs.
  5. Storage traffic flows through the VPC.

Interview Questions

1. What is EC2?

AWS virtual machine service used to run applications and workloads.

2. What is ENI?

A virtual network adapter attached to AWS resources.

3. What is VPC?

A private virtual network inside AWS.

4. Can an EC2 instance have multiple ENIs?

Yes, depending on instance type.

5. Why are ENIs important for FSx for ONTAP?

They provide management, NFS, SMB and iSCSI connectivity.

6. Is VPC similar to a VLAN?

No. VPC is an entire network; Subnets inside the VPC are more comparable to VLANs.
