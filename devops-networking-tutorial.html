Ansible Automation

Core What is Ansible?

An open-source automation tool for configuration management, application deployment, and task automation. Written in Python; playbooks use YAML.

🚫 Agentless

No software needs to be installed on managed nodes. Uses SSH (Linux) or WinRM (Windows) to connect.

♻️ Idempotent

Running a playbook multiple times produces the same result as running it once — safe to re-run.

📐 Architecture

Control Node runs playbooks via SSH to Managed Nodes. Inventory lists hosts; modules perform the actual tasks.

Playbook Structure (YAML)
site.yml 
---
- hosts: webservers
  become: yes          # run as sudo
  tasks:

    # Task 1: Install Nginx
    - name: Install Nginx
      apt:
        name:          nginx
        state:         present
        update_cache:  yes

    # Task 2: Start Nginx service
    - name: Start Nginx Service
      service:
        name:     nginx
        state:    started
        enabled:  yes

    # Task 3: Copy index page
    - name: Copy Index Page
      copy:
        src:  index.html
        dest: /var/www/html/index.html
Inventory File
inventory.ini 
[webservers]
web1.example.com
web2.example.com

[dbservers]
db1.example.com
Running a Playbook
terminal 
ansible-playbook -i inventory.ini site.yml

# -i  = inventory file path
# The final argument is your playbook file
Key Playbook Components
hosts:
Defines the target hosts or group from inventory
become:
Execute tasks with sudo / root privileges
tasks:
List of tasks to be executed in order
module:
Specific action to perform (apt, service, copy, etc.)
name:
A human-readable description shown in playbook output
Common Ansible Modules
apt / yum
Package management (Debian / RHEL)
service
Start, stop, restart, enable services
copy
Copy files to managed nodes
file
Manage files and directories
user
Manage OS user accounts
template
Render Jinja2 templates to nodes
command
Run arbitrary shell commands
git
Clone / manage Git repositories
