FSx for ONTAP runs inside an AWS VPC and is accessed through IP networking. Clients connect through NFS, SMB, or iSCSI protocols.

2. What is a VPC?

VPC (Virtual Private Cloud) is your private network in AWS. 

VPC CIDR:
10.0.0.0/16

Available range: 

10.0.0.0 - 10.0.255.255

All EC2 instances and FSx resources communicate inside the VPC.

3. What is a Subnet?

A subnet is a smaller network created from the VPC address space. 

VPC:
10.0.0.0/16

Subnets:

10.0.1.0/24
10.0.2.0/24
10.0.3.0/24

Resources such as EC2 and FSx are deployed into subnets.

4. EC2, ENI, Subnet and VPC Relationship

VPC
 |
 +-- Subnet
      |
      +-- ENI
            |
            +-- EC2

Many interview candidates incorrectly think EC2 belongs directly to a VPC.

Correct Hierarchy: VPC → Subnet → ENI → EC2

5. What is an ENI?

ENI = Elastic Network Interface.

Think of it as a virtual network card. 

Physical Server
      |
      +-- NIC

AWS

EC2
 |
 +-- ENI

An ENI provides:

  • Private IP Address
  • MAC Address
  • Security Groups
  • Subnet Membership

Without an ENI, an EC2 instance cannot communicate.

NACLs operate at the subnet level.

 |
Security Group
 |

Both Security Groups and NACLs must allow traffic.

9. Route Tables

Route tables determine where packets go. 

Destination      Target

10.0.0.0/16      Local
0.0.0.0/0        Internet Gateway

When an EC2 instance accesses FSx inside the same VPC, the route is usually: 

10.0.0.0/16 -> Local

10. Storage Virtual Machine (SVM)

FSx File System
       |
       +---- SVM1
       |
       +---- SVM2

An SVM is a logical storage server inside ONTAP.

Clients connect to SVMs, not directly to disks.

11. Logical Interfaces (LIFs)

A LIF is a logical IP address presented by ONTAP. 

NFS LIF      10.0.2.100
SMB LIF      10.0.2.101
iSCSI LIF    10.0.2.102
Mgmt LIF     10.0.2.103

Clients connect to these IP addresses.

LIFs can move between nodes during failover.

12. Data LIF vs Management LIF

Type Purpose
Data LIF NFS, SMB, iSCSI traffic
Management LIF SSH, CLI, REST API, System Manager

13. NFS Connectivity

Linux systems commonly use NFS. 

mount -t nfs 10.0.2.100:/vol1 /mnt/data

14. SMB Connectivity

Windows clients typically use SMB. 

\\files.company.com\share

SMB depends heavily on DNS and Active Directory.

17. Multi-AZ Architecture

AZ1                    AZ2

Node A (Active) <----> Node B (Standby)

If Node A fails: 

Node B becomes Active

LIFs migrate automatically.

Client configuration remains unchanged.

18. FSx ENIs

FSx also uses Elastic Network Interfaces. 

FSx
 |
 +-- ENI
      |
      +-- Private IP

For Multi-AZ deployments AWS manages multiple ENIs for data access, management, and failover operations.
